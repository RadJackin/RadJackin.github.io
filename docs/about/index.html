关于

你好，我是JeffJack。独立开发者，平时写代码、写点东西、做几个没人用的小工具。

这个博客记录三件事：技术笔记（踩过的坑和最后的解法）、建站日志（这个网站本身怎么长出来的）、作品（做出来给别人看的东西）。

我写博客不是为了教谁，主要是因为——一个人做事的时候，如果没人验收，很容易自己骗自己。写下来会老实很多：写不清楚的地方，通常就是没想清楚的地方。

现在在做什么

在维护这个博客本身：把阅读体验做好、把发文流程压到 30 分钟以内。另外有几个还没成形的小项目，做出来会写在这里。

这个博客怎么搭的

静态站点，Astro 构建，托管在免费 CDN 上。没有数据库、没有后台、没有插件——文章就是仓库里的 Markdown 文件，所以十年后它大概率还能跑。

个人博客上线要花多少钱：一张真实账单

2026.10.05 · 2 分钟 · #建站#成本

一句话结论：可以 ¥0 跑起来，也可以用 ¥300/年 跑得很舒服。真正贵的不是钱，是你愿意为它花多少时间。

先说结论

项目0 元方案体面方案说明
域名用平台子域名¥60～120/年.com 约 ¥70～90；.me/.dev 约 ¥100～150
托管GitHub Pages / Vercel / Cloudflare Pages同左免费额度对个人博客绰绰有余
HTTPS自动自动不用买证书，早就不用买了
评论Giscus（GitHub 账号登录）同左免费、无广告、数据在你自己的仓库里
统计不装Umami Cloud 免费额度想看”哪篇文章有人读”才需要
图床图片放仓库同左单张压到 200 KB 以内就够
备案不需要不需要只有服务器在中国大陆才需要 ICP 备案
合计¥0 / 年¥60～150 / 年 + 可选 ¥0不含你的时间

容易被漏掉的四项

1. 时间才是最大成本

搭站本身一两天能搞定（这套站是 2 小时搭完的）。真正的成本在于：

  • 每周写一篇：2～3 小时，一年 120 小时；
  • 维护：静态站几乎没有维护，但你要记得备份（Git 仓库本身就是备份）；
  • 学一点点：Markdown 半小时，Git 三小时。

如果你只想”有个主页”，别搭博客——花 10 分钟做个单页就够了。博客的价值只在持续更新。

2. 免费托管的”隐性条款”

  • GitHub Pages：免费账号要求仓库公开（代码公开，不是隐私问题，但你得接受）；
  • Vercel / Cloudflare 免费版：个人项目免费，商用或流量超标会提示升级；
  • 免费域名（*.github.io、*.vercel.app）在部分网络环境下速度不稳定。

3. 域名续费涨价

首年 ¥9、¥19 的促销域名，第二年常按原价（¥70～100）续。买的时候看清楚续费价，别只看首年。

4. 图片会悄悄变大

一篇带 10 张截图的文章，如果不压缩，轻松 20 MB。访客在手机上打开要等十几秒。这是我的第一优先级：发布前把所有截图压到 200 KB 以内。

一个更现实的问题：值不值

我给自己的判断标准：

如果这个博客让我多想清楚一件事，它就值那 ¥100 的域名钱。

一年下来，写博客最大的收益不是”有人看”，而是被迫把模糊的想法写成能读的句子——这个过程会暴露大量”其实没想清楚”的地方。这个价值很难量化，但对我确实存在。

而如果你的目标只是”有个地方放文章”，公众号 / Substack 的成本是 0，还自带流量。独立博客的收益是控制权，代价是没人给你导流。

最后

  • 只想试试 → 用平台，别搭站；
  • 想长期写、想完全掌控 → 独立静态站，¥0 起步；
  • 决定长期写 → 第二年再买域名，那时你已经知道它值不值。

下一篇写：一个人维护一个博客，最难的不是技术。
